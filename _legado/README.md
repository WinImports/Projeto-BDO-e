# BDO-e (Boletim Diário de Operações Eletrônico)

Desenvolvido para gestão rápida e offline de operações em campo.

## Como rodar o projeto no VS Code com Claude Code:
1. Extraia o conteúdo deste arquivo ZIP em uma pasta do seu computador.
2. Abra o VS Code nessa pasta.
3. Abra o terminal do Claude Code e execute as instruções contidas neste repositório para conectar ao seu Supabase e personalizar o layout.
